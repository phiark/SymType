## Open decision procedure

Low-risk defaults may proceed as **Provisional** with tests and a change trigger. Ask the user only when an ambiguity would materially change the data model, finger mapping, training semantics, safety, or product scope. Record discoveries in `PLANS.md`; promote, supersede, or add decisions here when implementation evidence resolves them.
