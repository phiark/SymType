# SymType content notice

## Original material

The curated vocabulary, sentence templates, generated-data formats, code snippets, original prose, and Pineapple Breach text were created for SymType using a clean-room process. They are dedicated under CC0 1.0 Universal. The vocabulary order is a teaching-oriented curation, not a claim of exact frequency in a named corpus.

## Historical public-domain material

The package includes a short excerpt from L. Frank Baum's _The Wonderful Wizard of Oz_, first published in 1900. It is treated as public domain in the United States. Public-domain status can vary by jurisdiction, so distributors outside the United States should check local requirements.

## Safety boundary

Game strings describe a fictional stage production in the invented Pineapple Company world. They do not contain real network locations, executable system commands, working credentials, private-key material, or wallet recovery phrases. Finale strings use invented tokens, digits, punctuation, and explicit prop labels so they cannot be mistaken for a standard mnemonic.
